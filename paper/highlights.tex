\section*{Highlights}
\begin{itemize}
  \item Imputation, feature selection and stacking were all fitted inside validation.
  \item Stacking did not beat logistic regression (CV AUC 0.843 vs 0.842).
  \item RFECV cut inputs by 25\%, with a stable feature core of glucose and BMI terms.
  \item Probabilities were too high, consistent with class weighting.
  \item Findings replicated in an independent NHANES cohort with an HbA1c outcome.
\end{itemize}
