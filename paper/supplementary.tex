\section{Validation design: where each loop runs}

Figure~\ref{fig:nested} shows the complete validation design. There are three nested levels. The \emph{outer} level is the 5$\times$10-fold repeated cross-validation used for model comparison. Within each outer training part there are two \emph{inner} levels: the 5-fold cross-validation that RFECV uses to choose the subset size, and the 5-fold split that produces out-of-fold probabilities for the stacking meta-learner. The 154-patient hold-out set is separated before any modelling and is used once, by the final pipeline refitted on all 614 development patients.

\section{Statistical testing procedure}

\paragraph{Repeated cross-validation}
Let $x_{rk}$ be the value of a metric on fold $k$ of repeat $r$ ($r=1,\dots,5$; $k=1,\dots,10$; $J=50$). The point estimate is $\bar x = J^{-1}\sum_{r,k} x_{rk}$. Fold estimates share most of their training data, so the naive variance $s^2/J$ is too small. Following Nadeau and Bengio, we use
\begin{equation}
\widehat{\operatorname{Var}}(\bar x) = \left(\frac{1}{J} + \frac{n_{\mathrm{test}}}{n_{\mathrm{train}}}\right) s^2, \qquad \frac{n_{\mathrm{test}}}{n_{\mathrm{train}}} = \frac{1}{9},
\end{equation}
with $s^2$ the sample variance of the $J$ fold estimates. 95\% confidence intervals are $\bar x \pm t_{0.975,\,J-1}\sqrt{\widehat{\operatorname{Var}}}$.

\paragraph{Paired comparisons}
For a configuration $A$ and the reference $B$ (logistic regression on all features), $d_{rk} = x^{A}_{rk} - x^{B}_{rk}$ is computed on identical folds. The corrected resampled statistic is $t = \bar d / \sqrt{(1/J + 1/9)\,s_d^2}$, referred to a $t$ distribution with $J-1 = 49$ degrees of freedom (two-sided). The analysis comprises 23 configurations: 11 learners $\times$ 2 feature sets (all 16 predictors or the common RFECV subset) = 22, plus logistic regression with its own LR-ranked RFECV. Each of the 22 non-reference configurations is compared with the reference (logistic regression on all 16 predictors), and the 22 $p$-values are adjusted with the Holm step-down procedure. This comparison set was fixed in the analysis code before the repeated cross-validation was run.

\paragraph{Why this test}
The corrected resampled $t$-test is designed for exactly this setting, where fold estimates from repeated $k$-fold cross-validation are correlated. In simulation studies it keeps the type~I error close to the nominal level and replicates well across random partitions, whereas the uncorrected paired $t$-test is anti-conservative. Alternatives such as a nested bootstrap of the whole pipeline or Bayesian correlated $t$-tests are valid. However, a nested bootstrap would have required thousands of refits of RFECV and the stack (about 45~s each), and the conclusions here are far from any decision boundary: the stacking--logistic-regression difference is $+0.001$ with an adjusted $p = 1.00$.

\paragraph{Hold-out set}
ROC-AUC confidence intervals and pairwise comparisons on the 154 hold-out patients use DeLong's non-parametric covariance (fast mid-rank implementation), with Holm adjustment over six comparisons against stacking + RFECV. All other metrics use 95\% percentile bootstrap intervals from 2000 resamples of hold-out patients; resamples containing a single class are discarded.

\paragraph{Calibration and thresholds}
The calibration intercept is estimated from $\operatorname{logit} P(y=1) = a + \operatorname{logit}\hat p$ (offset model) and the slope from $\operatorname{logit} P(y=1) = a' + b\operatorname{logit}\hat p$, both by Newton--Raphson maximum likelihood. For a target sensitivity $s$, the threshold is the largest value $t$ for which at least $\lceil s\,n_+\rceil$ of the $n_+ = 214$ development-set positives have an out-of-fold probability (averaged over the five repeats) of at least $t$, i.e.\ the $\lceil s\,n_+\rceil$-th largest positive probability. Patients with probability $\geq t$ are flagged, so ties at the threshold are always flagged. The pooled out-of-fold calibration analysis uses all 3070 predictions (614 unique patients $\times$ 5 repeats). The development prevalence is $214/614 = 0.349$ ($\operatorname{logit} = -0.626$).

\section{Software environment and reproduction}

All results were produced by commit \texttt{e23102d} of \url{https://github.com/subrahmanyamtanala-rgb/T2D} with Python 3.11, scikit-learn 1.9.1, XGBoost 3.2.0, LightGBM 4.7.0, SHAP, NumPy, pandas and SciPy, using random seed 42 throughout. The dataset is included in the repository as \texttt{data/diabetes.csv}. It was obtained from the public mirror \url{https://raw.githubusercontent.com/jbrownlee/Datasets/master/pima-indians-diabetes.data.csv}, a header-less copy of the 768-record UCI PIMA Indians Diabetes Database, and a header row with the standard column names was added. The file has 768 records and 268 positive outcomes, and its SHA-256 checksum is \texttt{3c7023e0935097ac63e03c6f398928b6dfce30974d5591d3af09a9661876d9fe}. Before submission, the author should confirm that it matches the UCI or Kaggle distribution, which have the same record and class counts. To reproduce:

\begin{verbatim}
pip install -r requirements.txt shap
python -m t2d.analysis --stage cv        # ~40 min on 4 CPU cores
python -m t2d.analysis --stage holdout   # ~7 min
python -m t2d.analysis --stage missing   # ~35 min
paper/build.sh                           # all tables, figures and PDFs
\end{verbatim}

Fold-level metrics, out-of-fold predictions, hold-out predictions and SHAP values are provided in \texttt{results/revision/}.

\paragraph{Reproducibility check} Commit \texttt{881d84f} only renamed the derived feature \texttt{Hyperglycemic} to \texttt{IGT\_2h}; the computation depends on column order, not names. To check reproducibility and the rename, the hold-out stage was re-run in a fresh output directory at that commit. All hold-out predictions, metrics, bootstrap intervals, DeLong tests, thresholds, calibration estimates, decision curves and SHAP summaries matched the reported values to within floating-point rounding (maximum absolute difference $2.2\times10^{-16}$). The 50-fold cross-validation and missing-data stages were not re-run for this check.

\paragraph{Random seeds} Every stochastic operation uses seed 42:
\begin{itemize}
  \item the stratified 80/20 split (\texttt{train\_test\_split});
  \item the repeated outer folds (\texttt{RepeatedStratifiedKFold}, 10 folds $\times$ 5 repeats; 10 $\times$ 2 for the missing-data analysis);
  \item the inner 5-fold splits of RFECV and of the stacking meta-learner (\texttt{StratifiedKFold}, shuffled);
  \item the RFECV random-forest ranker and every learner with a random component (LR, SVM, decision tree, random forest, extra trees, gradient boosting, XGBoost, LightGBM);
  \item the iterative imputer;
  \item the bootstrap resampling (NumPy \texttt{default\_rng});
  \item the 40-patient SHAP background sample (\texttt{DataFrame.sample}).
\end{itemize}
The Platt calibration of the SVM uses deterministic, unshuffled internal folds. $k$-NN, naive Bayes and median or $k$-NN imputation are deterministic.

\paragraph{Eligibility} Of 2909 OGTT-subsample records, 2345 had a 2-h glucose value, 1858 of these were aged $\geq 21$ years and 1815 also had fasting insulin and HbA1c. Diastolic blood pressure was the mean of the valid readings; a recorded value of 0~mmHg was treated as missing (the SAS transport format stores it as a value of order $10^{-79}$). BMI was missing for 9 and blood pressure for 41 participants; both were imputed inside the validation folds.

\paragraph{Cohort and outcome} 1815 adults (929 women), 551 with HbA1c $\geq 5.7\%$ (30.4\%) and 58 with HbA1c $\geq 6.5\%$. The derived file \texttt{data/nhanes\_2013\_2014\_ogtt.csv} has SHA-256 \nolinkurl{eb56eb115abe320ecba06f12fb548c776a67778dd7d605c71a78996570f2f640}; a unit test checks that it is rebuilt exactly from the six files.

\paragraph{Earlier processed copy} An earlier version of this analysis used a third-party processed copy (\url{https://github.com/ChintanaL/diabetes-prediction-using-nhanes-dataset}, commit \texttt{074e664}), because the CDC site could not be reached from the analysis environment. Its laboratory file covers only 1454 OGTT participants and yielded 902 of the 1815 eligible adults. For these 902 adults every sex, age, BMI, glucose, insulin and HbA1c value equals the official one; diastolic blood pressure differs because the copy used only the second reading. All results reported here use the official files.

\paragraph{Reproduction} \texttt{python -m t2d.nhanes --cdc data/nhanes\_cdc} rebuilds the cohort. The analysis is then re-run with \nolinkurl{python -m t2d.analysis --dataset nhanes --output-dir results/external_nhanes} and \texttt{--stage cv}, \texttt{--stage summarize} and \texttt{--stage holdout}.
